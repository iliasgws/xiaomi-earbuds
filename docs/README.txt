Makealight vector assets

Hand-redrawn from the supplied photograph, preserving its visible proportions.
Light: white shapes; black: black shapes. Both have transparent backgrounds
and 23% opacity stems, matching the tonal hierarchy of the reference.
True paths only: no embedded bitmap, fonts, external assets, filters or shadows.
512 x 512 shared viewport. Openings are transparent.

Android: copy ic_makealight_light.xml and ic_makealight_black.xml to
app/src/main/res/drawable/. Reference @drawable/ic_makealight_light or
@drawable/ic_makealight_black. Avoid applying a tint if preserving both tones.
The XML files use evenOdd fillType (platform API 24+).
SVG files are provided for tools/libraries that accept SVG.

Reconstruction from a photograph, not an original-source export.
